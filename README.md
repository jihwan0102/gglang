# 줴줴이랭 (gglang)

요새 20대 남성 사이 유행하는 말투인 "아 예? 엄 줴줴이야~" 등으로 만든 난해한 프로그래밍 언어. 
[엄랭](https://github.com/rycont/umjunsik-lang)에서 여러 아이디어를 차용해 만들었음.

```
쥐~랄 아뇨아뇨아뇨아뇨아뇨
요이~
줴줴이야 쥐~랄
티~원 쥐~랄
티~~원
쥐~랄 쥐~랄엄아뇨
요이~
```
```
5
4
3
2
1
```

- playground: https://gglang.jihwan.kim (설치 없이 브라우저에서 실행)
- 확장자: `.ggya` (아 줴줴이야~)

## 설치

```bash
pip install gglang
```

Python 3.8 이상

## 실행

```bash
gglang hello.ggya
python -m gglang hello.ggya   # 같음
```

## 문법

### 숫자

`아뇨` 하나가 1이다. 붙여 쓴 `아뇨` 개수가 값이다.

| 코드 | 값 |
|---|---|
| `아뇨` | 1 |
| `아뇨아뇨아뇨` | 3 |

### 계산

**붙여 쓰면 더하기, 띄어 쓰면 곱하기.** 붙어 있는 덩어리(항)마다 먼저 더하고, 항끼리 왼쪽부터 곱한다.

| 코드 | 계산 | 값 |
|---|---|---|
| `아뇨아뇨쥐~랄` | 2 + 변수 | |
| `아뇨아뇨 아뇨아뇨아뇨` | 2 × 3 | 6 |
| `아뇨아뇨 아뇨아뇨아뇨아뇨` | 2 × 4 | 8 |

### 음수: `엄`

원소 바로 앞에 붙인 `엄`은 그 원소 하나의 부호를 뒤집는다.

| 코드 | 값 |
|---|---|
| `엄아뇨` | -1 |
| `엄아뇨아뇨아뇨` | -3 |
| `쥐~랄엄아뇨` | 변수 − 1 |
| `엄엄아뇨아뇨` | 2 |

### 부정: `엄 ` (엄 + 공백)

식 **맨 앞**에 `엄`과 공백을 쓰면 식 전체를 부정한다. 0이면 1, 아니면 0. 같은지 비교할 때 쓴다.

| 코드 | 값 |
|---|---|
| `엄 쥐~랄` | 변수가 0이면 1, 아니면 0 |
| `엄 쥐~랄엄아뇨아뇨아뇨` | 변수가 3이면 1, 아니면 0 |

### 변수

`쥐` + `~` + `랄`. 물결 수가 변수 번호다. 처음 값은 0.

| 코드 | 뜻 |
|---|---|
| `쥐~랄` | 1번 변수 |
| `쥐~~~랄` | 3번 변수 |
| `쥐~랄 아뇨아뇨아뇨` | 1번 변수 = 3 |
| `쥐~랄 쥐~랄엄아뇨` | 1번 변수 = 1번 변수 − 1 |

### 입력: `아 예?`

한 줄을 읽어 정수로 바꾼다. 식 안에서 원소처럼 쓴다.

```
쥐~랄 아 예?
```

### 출력: `티~원`, `티~~원`

| 코드 | 출력 |
|---|---|
| `티~원 식` | 숫자 (줄바꿈 없음) |
| `티~원` | 공백 한 칸 |
| `티~~원 식` | 값을 유니코드 번호로 보고 문자 하나. 65 → `A` |
| `티~~원` | 줄바꿈 |

글자는 `티~~원 식`으로 한 글자씩 번호로 출력한다.

### 반복: `요이~`

물결 수가 같은 두 `요이`가 짝이 되어 반복 구간을 감싼다. 닫는 `요이`에 오면 여는 `요이` 다음으로 돌아간다. 겹쳐 쓰려면 물결 수를 다르게 한다.

```
요이~
  …
  요이~~
    …
  요이~~
요이~
```

### 탈출: `줴줴이야`

| 코드 | 뜻 |
|---|---|
| `줴줴이야 식` | 식이 **0이면** 탈출, 아니면 계속 |
| `줴줴이야` | 무조건 탈출 |

가장 안쪽 반복의 닫는 `요이` 다음으로 간다. 반복 밖에서 쓰면 프로그램이 끝난다.

## 예제

### GG 출력

```
쥐~랄 아뇨아뇨아뇨아뇨아뇨아뇨아뇨아뇨 아뇨아뇨아뇨아뇨아뇨아뇨아뇨아뇨아뇨
쥐~랄 쥐~랄엄아뇨
티~~원 쥐~랄
티~~원 쥐~랄
```
```
GG
```

### 0이 나올 때까지 입력받아 합계

```
요이~
쥐~랄 아 예?
쥐~~랄 쥐~~랄쥐~랄
줴줴이야 쥐~랄
요이~
티~원 쥐~~랄
티~~원
```
입력 `3`, `5`, `0` → `8`

## 에러

```
아 예? 엄 줴줴이야~ 3번째 줄: 모르는 명령 '페이커'
```
